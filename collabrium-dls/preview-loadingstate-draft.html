What's adapted vs. excluded

  • Included: Drive, Dots, Orbit — all three ported as their own .c-loading-grid modifier.
  • Colors: bg-ink → var(--color-neutral-9); elapsed timer → var(--color-neutral-5), the same muted tone Price summary card's costs and Chat's timestamps already use.
  • Typography: label and timer both render in var(--font-primary) — no monospace font introduced for the timer; numeral alignment comes from font-variant-numeric: tabular-nums instead, matching this system's existing precedent.
  • Motion: ease-in-out → var(--ease-standard). Per-cell cycle lengths (650ms / 950ms) and the delay tables that create the wavefront/comet are kept as the source's own tuned literal values.
  • Label — animation removed on request: the source shimmered the label; this went through a pastel-clipped version (too low-contrast, reverted to grayscale) and then the grayscale shimmer itself was judged too much movement next to the grid's own animation. Removed rather than toned down — the label is now plain, static Neutral-9 text, same treatment as the elapsed timer beside it. All motion in this component now lives in the grid.
  • Collabrium pastel gradient — added on request, grid only: the grid cells step through Gold → Water → Wood → Fire → Earth one flat color at a time (c-loading-color-cycle, a new keyframe animating background-color) rather than a moving gradient — the first pass reused Prompt input bar's own c-prompt-bar-glow-move gradient sweep, but at 4px the gradient's stops blended into each other within a single dot, showing several hues at once instead of one. Layered under each cell's existing opacity pulse, so color and brightness still animate independently on different cycles.
  • Reduced motion: newly added — the source component didn't define this keyframe or its own reduced-motion behavior explicitly in the code shared. The grid's fallback follows Banner-ai's "freeze the wash in place" precedent (settles on a flat Gold-pastel frame at each cell's own resting opacity). The label has nothing to freeze — it was already static before reduced motion entered the picture.

Excluded — Surfer variant. The meme-video card (autoplay <video>, video-load-failure fallback state, videoSrc prop) is not part of this draft. Only Drive/Dots/Orbit were requested.
