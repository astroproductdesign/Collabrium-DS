Draft preview — not yet in components.css / DESIGN-SYSTEM.md / preview.html. Review here first; nothing lands in the real files until you say go. Two things worth a decision before this gets committed:
  • tokens.css has no --color-gold or --color-fire token — the real names are --color-amber (#FFA425, the Gold element) and --color-orange (#FF5825, the Fire element). This draft uses the real token names; the spec's element names and the token file's hue names just don't match 1:1.
  • The spec's .type-eyebrow/.type-h4/etc. read like utility classes, but no such layer exists anywhere else in this system — every other component (Card, Stat/KPI, Badge…) applies the token variables directly on its own scoped selectors instead. This draft follows that existing pattern (.c-herocard-heading{font-size:var(--text-h4-size)…}) rather than introducing a new generic type-utility layer. Say if you'd rather have the utilities as a real, reusable thing.
