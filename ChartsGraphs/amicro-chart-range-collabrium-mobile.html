Restyled against DESIGN-SYSTEM.md's Chart color mapping and Chart chrome & marks specs: categorical series walk the department table (Fire → Wood → Earth → Water → Gold), sequential ramps (Treemap/Pyramid/Donut/Funnel/Heatmap) run single-hue from an element's lightest tint to full strength, the Waterfall and Candlestick both use the diverging Green/Red pairing, gridlines are Neutral-3 (Y-axis only, no X-axis border), axis ticks are footnote/Neutral-5, bars are 4px-radius top-only and capped at Amicro's own thickness ceiling, and every chart carries a Secondary/sm "View as table" button except Bubble and Sankey (neither has an accompanying tabular form, per spec — Bubble by design, Sankey because Amicro's own source has no underlying data array to tabulate).

Hover tooltip: every mark with a real data point — bars, line/step/area points, donut and radial segments, bubbles, candles, bullet rows, treemap tiles, pyramid levels, sparkline rows — now shows its value via one shared floating tooltip per page, positioned to the cursor. It follows the Chart chrome spec's Tooltip rules literally: Neutral-1 surface, 1px Neutral-3 border, cornerRadius:8 / padding:10 (both literal, no matching token), title (the value) in label2/Neutral-9, body (the label) in label3/Neutral-5. Multi-series charts (Bar, Line, Composed, Waterfall, Stacked Bar, Stream) stack one value+label row per series. This goes further than Amicro's own source — real Amicro only wires a Recharts tooltip on charts built with Recharts primitives (about half of the 27) and leaves the hand-drawn DOM/SVG charts (Candlestick, Bullet, Treemap, Pyramid, Sankey) with no hover feedback at all; here, coverage is uniform because the ask was "display the data on hover," not "replicate Amicro's own gaps." One remaining honest gap: hover-only, not hover-or-keyboard-focus — marks aren't tabbable, so this doesn't yet satisfy the general Tooltip component's own keyboard-accessibility rule. Source charts: ChartsGraphs/Amicro--Micro-transitions--main/src/components/mono-charts/.
