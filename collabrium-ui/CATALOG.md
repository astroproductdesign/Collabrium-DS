# Catalog

What to use for each need. Only converted components are listed; the full
list of components still to convert is in MIGRATION-LOG.md.

| Need | Use | Don't use |
|---|---|---|
| Start an action on the current page (save, add, open, continue) | `Button`: `variant="primary"` for the one main action in a region, `"secondary"` beside it, `"ghost"` for low-emphasis, toolbar and table-row actions | A link styled as a button; a second Primary in the same region; an element/department colour as the fill |
| A compact action with no visible label | `Button iconOnly icon={…} aria-label="…"` (Tier 1 icon) | An icon with no `aria-label`; a Fill (Tier 2) icon |
| Show that an action is running | `Button loading` | Disabling the button; swapping the label for "Loading…" |
| Commit a destructive action (delete, revoke), or a text-level action inside a line of content | `Button variant="danger"` for the committing step of a destructive flow; `Button variant="link"` for "Show less" and similar | Danger for anything non-destructive or with the beacon; Link for a real link to another page; the opening "Delete…" step as Danger |
| Point to the single next step after something finishes | `Button variant="primary" beacon="on" trailingArrow="down"` | Beacon on page load or a timer; more than one beacon on a page; beacon on Secondary, Ghost, icon-only or disabled |
| Show the status or tone of something (Active, Pending, Failed) | `Badge variant="success" \| "warning" \| "error" \| "neutral"`; `"selected"` for the chosen item in a set | A Badge for ownership (that is Tag); a clickable or removable Badge (use Chip or Button); a solid brand fill with white text |
| Let the user pick any number of options, or switch one setting on or off and save it with a button | `Checkbox label="…"`; `indeterminate` only on a select-all box; `aria-label` when no visible label fits (a table row) | A Checkbox when only one option can be chosen (Radio) or when the setting applies instantly (Switch); a bare box with no name |
| Let the user pick exactly one option from a short set (up to four or five visible options) | `RadioGroup legend="…"` with `Radio value="…" label="…"` inside; `value` and `onValueChange` to control it; `required` and `error` for a group that needs a choice | A Radio when several options can be on (Checkbox) or when there are more than five (a select); mixing Radio and Checkbox in one group; an instant view switch (Segmented Control); Radio Card (needs Card, not converted yet) |
| Let the user flip one setting on or off and have it apply at once (no Save step) | `Switch label="…"` (what it controls, never its state); `checked` and `onChange`, or `defaultChecked`; `aria-label` when no visible label fits | A Switch in a form that needs a Save (Checkbox); picking one of several (Radio); picking several (Checkbox); a label that says "On" or "Off" |
| Filter a list or view by a few predefined options (status, department, pillar), or show the values a person has added to a field | `FilterChipGroup mode="single" or "multi"`, `aria-label`, `options` (`value`, `onValueChange`); `InputChipGroup aria-label chips onRemove` (folds past 3 into "+N") | A chip to label a status or owner (Badge, Tag); a filter chip as a form Checkbox; mixing input and filter chips or single and multi in one group; a filter row that wraps past two lines (Dropdown, multiple select) |
| Open a full conversation with the AI from the floating Prompt input bar: history, a thread, a composer | `ChatWindow open onClose origin title pillars groups composer` with `ChatMessage role="user"` or `"assistant"` as children; set the bar's `launched` to `open` | An inline chat in a page (it is a modal); a close button; a custom message layout; anything but `ChatMessage` in the thread |
| Let the user type one line of text, an email, a URL, a phone number or a number | `InputField label="…" helper="…"`; `required`, `error`, `success`, `size`, `leadingIcon` / `trailingIcon`, `prefix` / `suffix`, `showCount` with `maxLength` | A placeholder instead of a label; "(required)" or "(optional)" in the label; a pressable prefix or suffix (icon button); a quantity with − and + (Quantity selector); a password, search or several lines (their own components) |
| Let the user write several lines (a description, a note, a comment) | `Textarea label="…" helper="…"`; `required`, `error`, `showCount` with `maxLength`; it resizes vertically only, from 96px | A Textarea for one line (Input field); a placeholder instead of a label; horizontal resizing; a quick reply in a conversation (Prompt input bar) |
| Ask a question that takes one or more checkboxes, with a helper, a required marker and a group error | `CheckboxGroup legend="…" required error={…}` around `Checkbox`es; `required` and `error` on a single `Checkbox` for a must-tick box | Several checkboxes with no legend; `required` on every box in a group; an error left showing after a selection |
| Show that an AI operation is running before any result has arrived (model generation, tool execution, agent runs) | `LoadingState variant="orbit" label="Thinking" startedAt={…}`; update `label` as the phase changes; unmount it at the first streamed token; give the surface a Stop | A LoadingState for a data fetch, upload or table load (spinner or skeleton); two in one view; one that blocks the page or survives the first token |
| Show the named steps of an AI run as an expandable record (steps, reasoning, sources read, tool calls) once two or more steps exist and two seconds have passed | `Thinking variant="steps" \| "reasoning" \| "search" \| "coding"` with `status`, `workingLabel`, `doneLabel`; give the surface a Stop; hand off from `LoadingState` and never back | A Thinking before the first named step lands, with one step, or for work under two seconds (use `LoadingState`); two in one view; a variant chosen by preference |
| Show an AI answer arriving as it is produced, with citations in the sentence and actions once it settles | `StreamingText content={…} status="streaming" \| "done" \| "stopped"`; append to `content` as text arrives; start it at the first token and remove the Loading State or Thinking there | A StreamingText over text you already hold (cached, replayed, computed); a stream for a table, code or a list; a second one for the same answer; one that scrolls the page |
| Show an AI run of several named tasks, each with its own status, where one can fail while the others succeed | `TaskRows tasks={…} onRetry={…}`; `variant="list"` inside a card or panel; set `retryable` only on a transient failure | A TaskRows for one operation with ordered steps (use `Thinking`), data loading, or a checklist; a disabled Retry; a control on the row for something the reader must supply (ask in the conversation); two lists in one view |
| Ask the person's authorization before the AI does one specific, consequential action (read or write a file, run a command, send a message, call an outside service) | `PermissionPrompt status={…} risk={…} icon={…} details={…} onDeny={…} onAllowOnce={…} onAllowSession={…}`, in the AI's own turn; set `status` from the decision; set `expired` only when the conversation moves on | A PermissionPrompt for something that only affects the conversation, or to ask a question or get a decision (Tool approval); an overlay or modal; raw JSON or a truncated value in the detail; removing a resolved card; a control that sets Expired |
| Get one or more decisions from the person before the AI's task can go on (one question at a time, options plus a written answer) | `ToolApproval questions={…} onSend={…} onDismiss={…}`; `single` questions use radios and move on by themselves, `multiple` use checkboxes; raise a new instance for a later decision | A ToolApproval for authorizing a specific action (Permission Prompt); a general form; stacking two; disabling or hiding the dismiss; leaving a confirmation or a reopen button behind |
| Let the person ask the AI: a text box with a toolbar and a model switcher | `PromptInputBar variant="floating"` (pinned over a region, collapses on scroll with `scrollContainer`, opens the chat with `onLaunch`) or `variant="inline"` (a chat window's composer); set `working` to turn Send into Stop | A PromptInputBar for a form field (Input field, Textarea); a scroll-collapse, a mark or the typing line on the inline variant; opening the chat from focus; hard-coded park or push offsets; a popover inside the bar with absolute positioning |
| Fade content in and out | `FadeIn` | CSS keyframes per screen |
| Slide content up into place | `SlideUp` | Custom transforms with other distances or springs |
| Expand and collapse a region | `Collapse` | `max-height` hacks |
| Chart.js defaults in brand style | `setupCharts()` from `@collabrium/ui/charts` | Hand-set chart fonts and colours |
| Draw a line, area, stream, step or range chart when Chart.js does not fit | `LineChart`, `AreaChart`, `StreamChart`, `StepChart`, `RangeChart` from `@collabrium/ui/charts-extra` (Recharts; `aria-label`, `data`, `categoryKey`, `series`; each has a table view) | Mixing both chart sets in one chart; a chart title inside the chart (the Card names it); colour as the only difference between series |
| Compare values across categories, parts within a total, a bridge between two totals, stages of a funnel, or measures against targets when Chart.js does not fit | `BarChart`, `StackedBarChart`, `WaterfallChart`, `FunnelChart`, `BulletChart` from `@collabrium/ui/charts-extra` (`BulletChart` is HTML and CSS) | Bar for a bridge between totals (Waterfall); a stack that does not sum to its label (`totalKey`); a ramp for different categories; Bullet for many categories |
| Show part of a whole as a ring, several measures against their limits, or one value on a dial when Chart.js does not fit | `DonutChart` (up to four slices), `RadialBarGroupChart`, `RadialGaugeChart`, `GaugeArcChart`, `MeterChart` from `@collabrium/ui/charts-extra` | A donut with more than four slices (Bar); a gauge to compare two values (Bar); a free colour for slices (`color` picks a hue, the slices walk its ramp) |
| Plot two or three measures against each other, a pattern across two categories, parts of a total as areas, or a calendar of daily counts when Chart.js does not fit | `ScatterChart`, `BubbleChart`, `HeatmapChart`, `TreemapChart`, `ActivityHeatmapChart` from `@collabrium/ui/charts-extra` | A scatter line between points; a rainbow ramp (one hue); a bubble chart with more than three series |
| Compare profiles across dimensions, volume by unordered category, levels of a hierarchy, flow between stages, or open-high-low-close per period when Chart.js does not fit | `RadarChart`, `PolarAreaChart`, `PyramidChart`, `SankeyChart`, `CandlestickChart` from `@collabrium/ui/charts-extra` | A "polar" chart of rings (Radial gauge); a sankey with a loop; colour alone for up and down in a candlestick |
| Bars with a line over them for two measures of the same categories, or a glance at a trend beside a figure, when Chart.js does not fit | `ComposedChart`, `SparklineChart` from `@collabrium/ui/charts-extra` | A sparkline with axes or a legend; a sparkline alone (use Line chart); a headline number as a chart (use Stat / KPI card) |
| Fade, slide or open content in and out, by token duration and easing | `FadeIn`, `SlideUp`, `Collapse` from `@collabrium/ui`; also `SlideDown`, `SlideLeft`, `SlideRight` from `@collabrium/ui/motion` | Your own numbers for duration or distance; a loader (use Loading State); bounce or overshoot |
